# Согласие на сбор аппаратных идентификаторов

## Зачем это нужно

Для фиксации установки серверов на устройство собираются **аппаратные идентификаторы** (hardware ID). Это необходимо для привязки установки к конкретному ПК и защиты от несанкционированного копирования.

## Что собирается

| Компонент | Описание | Стабильность |
|-----------|----------|-------------|
| **ID процессора** | Уникальный идентификатор CPU | Не меняется при смене ПО |
| **Серийный номер материнской платы** | Серийный номер motherboard | Не меняется при смене ПО |
| **Серийный номер диска** | Серийный номер системного диска | Не меняется при переустановке ОС |
| **Серийный номер BIOS** | Серийный номер BIOS/UEFI | Не меняется при смене ПО |

## Как это работает

1. При первом запуске стартера собираются аппаратные идентификаторы
2. На их основе генерируется **fingerprint** (SHA-256 хэш)
3. Fingerprint сохраняется локально и привязывается к установке
4. При повторной установке проверяется совпадение fingerprint

## Что НЕ собирается

- ❌ Имена файлов и папок
- ❌ Содержимое дисков
- ❌ Данные пользователей
- ❌ Пароли и ключи
- ❌ Сетевая активность
- ❌ Геолокация

## Передача данных

- Данные **не передаются** третьим лицам
- Данные хранятся **только локально** на вашем устройстве
- Данные используются **исключительно** для фиксации установки

## Если вы не согласны

Вы можете отказаться от сбора аппаратных идентификаторов. В этом случае будет использоваться **базовый fingerprint** (имя хоста + MAC-адрес + путь установки), который менее стабилен и может измениться при:
- Переименовании компьютера
- Смене сетевой карты
- Переносе папки стартера
