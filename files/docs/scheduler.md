# Планировщик задач

## Обзор

Планировщик позволяет запускать задачи по расписанию. Задачи выполняются как отдельные процессы — падение задачи не уронит стартер.

## Встроенные задачи

| Задача | Описание | Расписание |
|--------|----------|------------|
| check_updates | Проверка обновлений стартера | Ежедневно |
| check_service_status | Проверка статуса сервиса | Ежечасно |
| cleanup_logs | Очистка старых логов | Еженедельно |
| check_ports | Проверка портов | Ежедневно |
| check_docker | Проверка Docker | Ежечасно |

## Управление задачами

### Через веб-интерфейс

1. Перейдите в **Сервис**
2. Раздел **Планировщик задач**
3. Используйте кнопки:
   - ▶️ Запустить — выполнить немедленно
   - 📋 Лог — посмотреть результат
   - 🗑️ Удалить — убрать из списка
   - Вкл/выкл — включить/выключить по расписанию

### Через CLI

```bash
# Запуск конкретной задачи
python starter.py --task check_service_status

# С параметрами
python starter.py --task cleanup_logs --task-params '{"max_days": 30}'
```
