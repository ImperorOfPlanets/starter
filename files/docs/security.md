# Безопасность

## Аутентификация

### Веб-интерфейс

- Логин/пароль хранятся в `.env` (хеш SHA-256)
- Сессия хранится в файловой системе (`files/web/sessions/`)
- Cookie защищена HttpOnly + SameSite=Lax
- Сессия действительна 7 дней

### REST API

- Ключ API хранится в `files/crypto/.api_key`
- Передаётся в заголовке `X-API-Key`
- API не требует веб-сессию

## Защита от брутфорса

- Локкаут 60 секунд после неудачной попытки
- Прогрессивный бэкап: 60с → 120с → ... → 600с (максимум)
- Счётчик сбрасывается при успешном входе

## Безопасность сессий

- `SESSION_COOKIE_SECURE: True` — только HTTPS
- `SESSION_COOKIE_HTTPONLY: True` — недоступна из JavaScript
- `SESSION_COOKIE_SAMESITE: 'Lax'` — защита от CSRF
- `PERMANENT_SESSION_LIFETIME: 7 дней`

## API безопасность

- Все API эндпоинты требуют `X-API-Key`
- API ключ генерируется автоматически при первом запуске
- Ключ одноразовый — при потере нужно пересоздать

## Рекомендации

1. **Не коммитьте `.env`** — он в `.gitignore`
2. **Меняйте пароль** после первой установки
3. **Используйте HTTPS** — самоподписанный сертификат генерируется автоматически
4. **Не раскрывайте API ключ** — он даёт полный доступ
5. **Ограничьте доступ** к порту 2000 через файрвол
